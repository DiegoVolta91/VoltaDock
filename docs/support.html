Preguntas frecuentes

macOS dice que no puede verificar la app

La versión actual para Mac todavía no está notarizada por Apple. La primera vez, abre Ajustes del Sistema → Privacidad y seguridad, baja y haz clic en Abrir de todos modos. Solo hay que hacerlo una vez.

¿Dónde está la descarga para Windows?

Está en pausa por ahora. Microsoft Defender marca por error el instalador de Windows sin firmar como malware. El instalador volverá en cuanto esté firmado (ver la política de firma de código). Mientras tanto puedes compilarlo desde el código.

Volt no muestra mis sesiones de Claude Code

Abre Ajustes → Claude Code → Instalar hooks, revisa los cambios, confirma y abre una sesión nueva de Claude Code. VoltaDock hace una copia fechada de ~/.claude/settings.json antes de escribir nada.

Si cierro VoltaDock, ¿Claude Code se queda esperando?

No. Si la app no está abierta o no responde, el hook termina al instante y Claude Code te pregunta en la terminal como siempre.

El chat no responde

Agrega tu clave de API de Anthropic en Ajustes. Anthropic cobra el uso de la API por separado de una suscripción a Claude.

Una integración se queda gris

Revisa su clave en Ajustes → Integraciones. Se pueden mostrar hasta 4 integraciones a la vez.

No se oye nada

Revisa el ícono de bocina en la parte de arriba de la isla y el volumen en Ajustes.

¿Cómo la desinstalo?

Ajustes → Claude Code → Desinstalar (quita solo los hooks de VoltaDock), luego cierra la app y muévela a la Papelera. Si quieres, borra también ~/Library/Application Support/VoltaDock.

En Windows: el mismo botón para quitar los hooks, luego Configuración de Windows → Aplicaciones → VoltaDock → Desinstalar. Si quieres, borra también la carpeta de datos de la app en %LOCALAPPDATA% (por ahora todavía se llama Coucou, el nombre del proyecto original; pronto pasará a VoltaDock).

FAQ

macOS says it can't verify the app

The current Mac build isn't notarized by Apple yet. The first time, open System Settings → Privacy & Security, scroll down and click Open Anyway. You only need to do it once.

Where is the Windows download?

It is paused for now. Microsoft Defender wrongly flags the unsigned Windows installer as malware. The installer will come back once it is signed (see the code signing policy). Until then you can build it from source.

Volt doesn't show my Claude Code sessions

Open Settings → Claude Code → Install hooks, review the changes, confirm, then start a new Claude Code session. VoltaDock makes a dated backup of ~/.claude/settings.json before writing anything.

If I quit VoltaDock, does Claude Code hang?

No. If the app isn't running or doesn't answer, the hook exits immediately and Claude Code asks in the terminal as usual.

The chat doesn't answer

Add your Anthropic API key in Settings. API usage is billed by Anthropic, separately from a Claude subscription.

An integration stays grey

Check its key in Settings → Integrations. Up to 4 integrations can be shown at once.

No sound

Check the speaker icon at the top of the island and the volume in Settings.

How do I uninstall?

Settings → Claude Code → Uninstall (removes only VoltaDock's hooks), then quit the app and move it to the Trash. Optionally delete ~/Library/Application Support/VoltaDock.

On Windows: same button for the hooks, then Windows Settings → Apps → VoltaDock → Uninstall. Optionally delete the app's data folder in %LOCALAPPDATA% (for now it is still called Coucou, the original project's name; it will move to VoltaDock soon).
