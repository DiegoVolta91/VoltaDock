Política de firma de código

Última actualización: 25 de noviembre de 2026
Firma de código gratuita proporcionada por SignPath.io, certificado de SignPath Foundation.

Qué se firma

El instalador de Windows publicado en la página de Releases y los dos programas que instala: la app y coucou-hook.exe, el pequeño intermediario que Claude Code ejecuta en cada evento de hook.

Todo lo que se firma lo compila GitHub Actions a partir del código público de github.com/DiegoVolta91/VoltaDock, desde una etiqueta de versión windows-v*. Nunca se firma nada compilado en una computadora personal. Solo se firman binarios compilados a partir del código de este proyecto; los programas de terceros nunca se firman con este certificado.

Roles del equipo

RolQuién
Autores y revisoresDiego (DiegoVolta91)
AprobadoresDiego (DiegoVolta91)

Los cambios de cualquier persona fuera del equipo se revisan en un pull request antes de integrarse. Cada solicitud de firma se aprueba a mano, versión por versión. Los miembros del equipo usan autenticación de varios factores en GitHub y en SignPath.

Privacidad

Este programa no transfiere información a otros sistemas en red salvo que lo pida expresamente el usuario o la persona que lo instala u opera. VoltaDock solo habla con los servicios que tú conectas; ver la política de privacidad.

Reportar un problema

Si crees que un archivo firmado de VoltaDock no se compiló a partir de este repositorio, o encuentras un problema de seguridad, abre un issue.

Code signing policy

Last updated: November 25, 2026
Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

The Windows installer published on the Releases page and the two programs it installs: the app itself and coucou-hook.exe, the small relay that Claude Code starts on every hook event.

Everything signed is built by GitHub Actions from the public source in github.com/DiegoVolta91/VoltaDock, from a windows-v* release tag. Nothing built on a personal computer is ever signed. Only binaries built from this project's own source are signed; third-party programs are never signed with this certificate.

Team roles

RoleWho
Committers and reviewersDiego (DiegoVolta91)
ApproversDiego (DiegoVolta91)

Changes from anyone outside the team are reviewed in a pull request before they are merged. Every signing request is approved by hand, release by release. Team members use multi-factor authentication on GitHub and SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. VoltaDock only talks to the services you connect yourself; see the privacy policy.

Reporting a problem

If you believe a signed VoltaDock file was not built from this repository, or you find a security issue, open an issue.
