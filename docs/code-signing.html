Code signing policy

Last updated: November 25, 2026
Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

The Windows installer published on the Releases page and the two programs it installs: the app itself and coucou-hook.exe, the small relay that Claude Code starts on every hook event.

Everything signed is built by GitHub Actions from the public source in github.com/DiegoVolta91/coucou, from a windows-v* release tag. Nothing built on a personal computer is ever signed. Only binaries built from this project's own source are signed; third-party programs are never signed with this certificate.

Team roles

RoleWho
Committers and reviewersDiego (DiegoVolta91)
ApproversDiego (DiegoVolta91)

Changes from anyone outside the team are reviewed in a pull request before they are merged. Every signing request is approved by hand, release by release. Team members use multi-factor authentication on GitHub and SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. VoltaDock only talks to the services you connect yourself; see the privacy policy.

Reporting a problem

If you believe a signed VoltaDock file was not built from this repository, or you find a security issue, open an issue.
